# Baby Tracker 🍼

A simple iOS app for tracking baby wakeup times and feeding times built with .NET MAUI.

## Features

- ☀️ **Record Wakeup Times** - Tap to log when the baby wakes up
- 🍼 **Record Feeding Times** - Tap to log feeding times  
- 📋 **View History** - See all recorded activities
- 📊 **Today's Summary** - View daily counts
- 🗑️ **Delete Records** - Swipe to remove entries

## Tech Stack

- .NET MAUI
- SQLite (in-memory)
- Tailwind-inspired UI

## Quick Start

1. Install .NET 10 SDK
2. Install MAUI workload: `dotnet workload install maui`
3. Build: `dotnet build -f net10.0-ios`
4. Run on simulator or device

See `INSTALL_INSTRUCTIONS.md` for detailed iOS installation steps.
